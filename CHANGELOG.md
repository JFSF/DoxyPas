# Changelog

## 1.0.0 — 2026-10-23

First release. / Primeira versão.

* Documentation generator for Object Pascal (Delphi, Free Pascal, Lazarus) based on Doxygen 1.19: units, classes, records,
  interfaces, helpers, generics, routines, properties, enumerations, forms (`.dfm`, `.fmx`), Delphi and Lazarus projects.
* Output: HTML (search, tree view, source browser, graphs through Graphviz `dot`), LaTeX/PDF, XML, SQLite, tag files, CHM files.
* All **221 options** of the Doxyfile are implemented; page texts in 12 languages.
* Command line tool (Win32, Win64, Linux64) and a VCL GUI (Win32, Win64) to edit the options and run it.
* Documentation in English and Portuguese with the reference of every option (`docs/`).
* Windows executables are not code-signed yet. / Os executáveis Windows ainda não têm assinatura de código.
